Food Delivery Landing Page

 Project Overview

This project is a responsive food delivery landing page developed as part of my Oasis Infobyte Internship (OIBSIP). 
The website is designed to provide users with a simple and attractive way to explore a food delivery service.

The landing page features a clean layout, food-related imagery, and easy navigation to help users discover the service and learn more about what it offers.

Responsive Design: Adapts to different screen sizes, including mobile phones, tablets, and desktops.

Sticky Navigation Bar: Keeps the navigation menu accessible while scrolling.

Navigation Links: Provides easy access to different sections of the page.

Food Images: Uses food-related images to create an appealing visual experience.

Clean User Interface: Presents information in a simple, organized, and professional layout.

Smooth Navigation: Makes it easier for visitors to move between page sections.

 Technologies Used


 HTML5 — For the structure and content of the webpage.

CSS3 — For styling, layout, responsiveness, and visual design.
